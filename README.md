# Chinnu Birthday Surprise — Windows desktop app

This is an interactive recreation of the provided screen recording. It follows the sequence: opening heart/arrow, birthday reveal, flower greeting, cake, poppable balloons with wish cards, memory photo upload, envelope, the exact personal letter from the supplied screenshot, and final birthday/confetti screen.

All navigation dots, Back/Next controls, arrow, cake button, balloons, photo uploads, envelope, letter action, sound toggle, and replay are wired up.

## Build on Windows
Requirements: Windows 10/11 and Node.js 20+. Extract the ZIP, then double-click `BUILD-WINDOWS.bat`. Or run `npm install` followed by `npm run dist` in this folder. The installer will be created under `dist/`.

To preview in a browser, open `src/index.html`.
